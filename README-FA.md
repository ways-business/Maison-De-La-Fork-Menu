# منوی دیجیتال Maison De La Fork

این پروژه کاملاً موبایل‌فرست است و روی نمایشگرهای بزرگ با عرض ثابت 430px در مرکز صفحه نمایش داده می‌شود.

## فایل‌هایی که باید اضافه شوند

سه تصویر اصلی را دقیقاً با این نام‌ها داخل پوشه `assets/images` قرار بده:

- `BackgroundDrawing.png`
- `cupid.png`
- `Logo.png`

فونت‌ها را با فرمت WOFF2 و نام‌های زیر داخل `assets/fonts` قرار بده:

- `Dahlia-MediumCondensed.woff2`
- `Dahlia-Bold.woff2`
- `Dahlia-Medium.woff2`
- `KoHo-Medium.woff2`

اگر نام فایل فونت‌های تو متفاوت است، فقط مسیر `src` در ابتدای فایل `styles.css` را تغییر بده.

## اجرا

برای تست سریع، فایل `index.html` را باز کن. برای نتیجه درست‌تر، پوشه را با یک سرور محلی اجرا کن؛ مثلاً با افزونه Live Server در VS Code.

## ساختار

- `index.html`: ساختار و محتوای منو
- `styles.css`: طراحی، فونت‌ها، گرین، ریسپانسیو و انیمیشن‌ها
- `script.js`: پری‌لودر، پارالاکس، ریویل هنگام اسکرول و تعامل لمسی
- `assets/icons`: آیکن‌های SVG اینستاگرام، یوتیوب و X
- `reference-design.png`: تصویر مرجع ارسالی

## تغییر سریع رنگ

رنگ‌های اصلی در ابتدای `styles.css` و داخل `:root` قرار دارند. متغیر اصلی پس‌زمینه آبی `--blue` است.
